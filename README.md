### Projects

- [**maternal-exposome**](https://github.com/nsarmadfar/maternal-exposome): untargeted exposome analysis of maternal
  blood in a matched case-control design, from drift correction and mass-based annotation to conditional logistic
  regression and mixture models. Tested on a simulated study, then applied to pregnancy exposures in the HELIX data.
- [**neoantigen-pipeline**](https://github.com/nsarmadfar/neoantigen-pipeline): from a tumour's somatic mutations and
  RNA-seq to the mutant peptides its own HLA class I molecules could present. Tested on simulated data, then run on
  the HCC1395 cell line.
- [**smc-evolution**](https://github.com/nsarmadfar/smc-evolution): how the SMC proteins (cohesin, condensin, SMC5/6)
  evolved across 14 eukaryotes from all six supergroups, with a maximum-likelihood tree.
- [**pathway-vae**](https://github.com/nsarmadfar/pathway-vae): a neural network for single-cell data in which every
  hidden variable is linked to a known pathway, so you can see directly which pathways are active in each cell.
  I tested it on simulated data and on human blood cells.
